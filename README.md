# Student Course Portal

A modern Student Course Portal built with Next.js and Tailwind CSS.

## Features

- Next.js App Router
- File-Based Routing
- Dynamic Routes
- Shared Layout
- Responsive Design
- Reusable Components
- Modern UI
- Tailwind CSS

## Pages

- Home
- Courses
- Course Details (Dynamic Route)
- Instructors
- Contact
- Custom 404 Page

## Technologies Used

- Next.js
- React
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
